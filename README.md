
# ARGUSS - Sistema de Domótica

Sistema de control domótico con almacenamiento de datos.

## Tecnologías

- HTML
- CSS
- JavaScript
- Node.js
- Express
- PostgreSQL

## Funciones del servidor

- Registro de usuarios.
- Inicio de sesión.
- Gestión de habitaciones.
- Guardado de estados.
- Historial de modificaciones.
- API para conectar dispositivos.

## Habitaciones iniciales

- Dormitorio 1
- Dormitorio 2
- Baño
- Antebaño
- Cocina-comedor
- Sala de estar
- Balcón

## Instalación

Instalar dependencias:

npm install

Iniciar servidor:

npm start
